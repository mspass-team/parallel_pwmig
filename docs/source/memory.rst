Memory Use Estimation
**********************
Assumptions
=============
This version of pwmig was written from the context of a world where
cluster nodes have memory measured in gigabytes and 16 or more cores.
My perspective is that memory size, in particular, is unlikely to shrink.

Concepts
=========
Borrow some from MsPASS  noting confusion of many people of what memory
means.   Need to discuss disk use and RAM and note this section is
mostly about RAM but has disk issues also due to manual virtual memory
use in pwmig.
